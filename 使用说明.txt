知言 · 陪伴版 使用说明

一、放到网上（二选一，都免费）
1. GitHub Pages
   新建一个仓库 → 把这个文件夹里的所有文件上传到仓库根目录
   → Settings → Pages → Branch 选 main，保存
   → 过一两分钟会给你一个 https://你的用户名.github.io/仓库名/ 的网址
2. Cloudflare Pages
   Workers & Pages → 创建 → Pages → 直接上传这个文件夹

二、装到手机桌面
- 安卓：用 Chrome 打开网址 → 右上角菜单 → 安装应用 / 添加到主屏幕
- iPhone：用 Safari 打开网址 → 分享 → 添加到主屏幕
（想要真正的 APK：用 Capacitor 或 PWABuilder.com 把这个网址打包即可）

三、第一次打开
自动弹出设置 → 选供应商 → 填 API Key → 点"测试连接" → 保存
然后点左上角头像或菜单里的"TA 的设定"：
  名字、关系、TA 怎么叫你、在一起的日子、性格、头像、主题色，都可以改。
  风格默认是"毛玻璃"，可以换成自己的照片当背景，拖"背景模糊"调透明感；不喜欢就切"简洁"。

四、陪伴功能
- 日历：可以手动加，也可以聊天时直接说"周六晚上七点提醒我去看海"，TA 会帮你记上。
        勾选"每年都记着"就是纪念日 / 生日，每年自动出现。首页会显示接下来 7 天的安排。
- 一起听：把手机里的歌加进来就能在 App 里放（歌只存在这台设备上）；
        放歌的时候 TA 知道你们在听哪一首，可以一起聊这首歌（TA 听不到声音，只知道歌名）；
        TA 推荐的歌会进歌单，点一下跳到网易云 / QQ 音乐。
- 心愿单：聊天时说"想买……"会自动记下，点淘宝 / 京东 / 小红书直接去搜。
- 小红书：让 TA 帮你找攻略、穿搭，会给你一个直接跳小红书搜索的卡片。
- 记忆：说"请记住……"TA 就会一直记得；也能导入 Claude / ChatGPT 导出的聊天记录。
- 画图：聊天时说"画一张……"，TA 会自己写画面描述去画，画好的图能点开看大图、保存、重画。
        默认用智谱的 cogview-3-flash（免费）：去 open.bigmodel.cn 注册拿一个 Key，
        填到 设置 → 画图 → 画图用的 Key。也可以换成 OpenAI（按张收费）。
        图片只存在这台设备上。
- 心情日记：随手记，TA 聊天时会参考最近三条（设置里可以关掉）。

说明：网页版没法在后台定时推送提醒，打开 App 时首页会显示接下来的安排。

五、如果提示"连不上接口"
说明这家供应商不让网页直接调用。
把 worker.js 部署成 Cloudflare Worker（步骤见下面第六条的 1、2 步就够了），
然后在设置的"接口地址"里填 https://你的worker地址/deepseek（或 /openai、/glm、/claude）。

六、TA 主动找你
1. 打开 App 时 TA 先开口：默认就开着，不用配置。隔 3 小时以上再打开，TA 会先说话。
2. App 关着也能收到 TA 的消息（通知）：需要一个免费的 Cloudflare Worker，大约 15 分钟：
   ① 去 dash.cloudflare.com 注册登录
   ② 左边 Workers 和 Pages → 创建 → 创建 Worker → 名字随便起（比如 zhiyan）→ 部署
      → 编辑代码 → 把 worker.js 里的全部内容粘贴进去，替换原来的 → 部署
   ③ 左边 存储和数据库 → KV → 创建命名空间，名字随便（比如 zhiyan）
   ④ 回到这个 Worker → 设置 → 绑定 → 添加 → KV 命名空间
      → 变量名填 ZY（大写），命名空间选刚才建的 → 保存
   ⑤ 设置 → 变量和机密 → 添加 → 类型选"密钥" → 名称填 PASS → 值填一个你自己想的密码 → 保存
   ⑥ 设置 → 触发事件 → 添加 → Cron 触发器 → 填 */10 * * * * （每 10 分钟看一次）→ 保存
   ⑦ 复制 Worker 的地址（https://zhiyan.xxx.workers.dev）
   ⑧ 知言 → 设置 → TA 主动找你 → 填地址和密码 → 点"开启通知"并允许通知
      → 点"让 TA 现在发一条"，手机收到通知就说明成功了
   可以设置每天主动找你几次、最早和最晚的时间，以及日程提醒
   （有具体时间的提前 30 分钟提醒，全天的早上 9 点提醒）。

   注意：
   - 安卓手机的网页通知走的是谷歌的推送服务。国内网络下通常要开着梯子，
     手机上还要有谷歌服务，才能收到通知（华为等没有谷歌服务的手机可能收不到）。
     收不到也没关系：TA 发过的消息都存在 Worker 里，下次打开 App 会自动出现在聊天里。
   - workers.dev 的地址在国内可能打不开，打不开时同样需要开梯子，或者给 Worker 绑一个自己的域名。
   - iPhone 需要 iOS 16.4 以上，先"添加到主屏幕"，再从桌面图标打开，才能开启通知。
   - 开启后，聊天用的 API Key 会同步到你自己的 Worker 上（别人看不到），TA 主动发消息也会消耗一点点额度。

七、更新
改了文件以后，把 sw.js 第二行的 zhiyan-v7 改成 zhiyan-v8（以此类推），
手机上关掉重开一次就是新版本。

八、数据
对话、记忆、日历、心愿、歌、Key 都只存在当前设备的浏览器里，不会上传到别处。
开启"TA 主动找你"的通知后，TA 的设定、记忆、最近几条聊天、近三天的日程和聊天 Key 会同步到你自己的 Worker，用来替 TA 说话。
换手机或清浏览器数据前，先在"记忆"里点"导出全部数据"做备份。
